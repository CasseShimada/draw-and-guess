# 0.5.10 信息架构与桌面控制中心验证记录

验证时间：2026-07-27（Asia/Shanghai）

验证分支：`develop`

应用版本：`0.5.10`

游戏协议版本：`5`（本次未升级）

主题 API 版本：`1`（本次未升级）

## 本次范围

1. Web 应用重新划分首页、大厅、游戏工作区、本局设置和全局辅助功能。顶部栏只保留
   品牌、单一房间码、模式/阶段、网络状态和“更多”入口。
2. 创建与加入房间成为首页主任务；模式选择、词库、本局参数、玩家状态和开始游戏
   集中在大厅；Pass、暂停、本局设置与返回大厅集中在当前阶段操作栏。
3. Electron 的联机、采集、偏好设置和诊断合并到单一桌面控制中心。远程玩家不会看到
   本机服务管理；实际主机的关闭房间操作保留在联机面板危险区。
4. 主动退出使用明确的 `DELETE /api/session` 会话流程。普通玩家立即从房间和会话表
   移除；逻辑房主退出时关闭房间；桌面客户端退出程序前尽力通知服务器并清理本地会话。
5. 默认 Web 与桌面主题改用一致的间距、圆角、轻边框、柔和阴影、状态 Badge 和
   主次/危险操作层级，并为 1440、1280、1024 和 390 宽度提供响应式规则。
6. 参考图画廊图片限制在卡片与视口内；主题 Shadow DOM 修复入口只在实际健康告警时
   显示。既有主题根、`data-ui`、`data-action` 和 `data-critical-*` 兼容钩子保留。

新增或更新的回归覆盖：

- 顶部栏只渲染房间与状态摘要，不重新引入词库、暂停等完整操作；
- “更多”菜单集中辅助功能和退出操作，危险操作位于菜单底部；
- 大厅只为逻辑房主提供模式控制，普通玩家得到只读摘要；
- 返回大厅只在结果阶段为逻辑房主显示，本局设置只在适用阶段显示；
- 桌面顶部只保留一个控制中心入口，中心内部同一时刻只选中一个分区；
- 远程玩家无法打开联机服务管理分区；
- 主动退出立即失效会话，意外断线仍保留原有重连语义；
- 主题稳定选择器、画廊图片约束和按告警显示的主题恢复入口。

## 发布构建

推送 `v0.5.10` 标签后，GitHub Actions 将在以下环境重新执行 `corepack pnpm check`、
生成安装包并启动打包应用冒烟：

- Windows x64；
- macOS arm64；
- macOS x64；
- Linux x64（Xvfb）。

只有全部平台任务成功后才会创建 GitHub 预发布 Release，并附带安装包、便携包与
`SHA256SUMS.txt`。

# 0.5.6 顶部工具栏与房间终止确认验证记录

验证时间：2026-07-26 08:47:56 +08:00

验证分支：`develop`

应用版本：`0.5.6`

协议版本：`4`

桌面设置 schema：`6`

## 用户可见修复

1. “联机 / 采集 / 设置 / 诊断”从右下角悬浮条移入首页操作区和房间顶部工具栏。
   页面底部不再存在会遮挡提示、联机表单或关闭房间按钮的桌面工具条。
2. 大厅中的“玩家连接信息”模块及其重复房间码横幅已删除。房间码只保留在左上角
   品牌区；服务监听、IPv4 网卡、公网映射、房间密码和关闭房间操作统一由“联机”
   面板承载。
3. “联机”面板使用最大 1040 px 的专用宽度、两列分区以及更大的说明和输入字号。
   1320 × 860 打包窗口中，说明文字计算字号为 13.76 px，输入框为 14.4 px。
4. 采集工作室裁切按钮显式设置前景色；启用态对比度为 15.46:1，禁用态为
   6.10:1，均超过 WCAG AA 普通文字的 4.5:1。
5. 房间被关闭后，远端玩家先看到带终止原因的不可忽略确认对话框。当前房间画面会
   保留到玩家点击“确定并返回主界面”，确认后才清理快照、房间码和本地画面。
6. 房主正常退出程序时，服务器关闭顺序调整为先广播
   “房主已退出，房间服务已停止”和 WebSocket 终止关闭码 `4004`，再关闭 WebSocket
   服务与进程，客户端不会把它误判为普通断线并持续重连。

JSON / 二进制游戏消息 schema 没有变化，因此 `PROTOCOL_VERSION` 保持 `4`。
